# autologin-ejudge.kruzhokinf

Пользовательский скрипт для Tampermonkey, который автоматизирует ввод email и нажатие кнопки входа при открытии контестов на [ejudge.kruzhokinf.com](https://ejudge.kruzhokinf.com).

## Как это работает

1. При первом запуске скрипт запрашивает email через всплывающее окно и сохраняет его в изолированное хранилище браузера (`GM_setValue`).
2. При входе на страницу контеста скрипт автоматически вставляет сохраненный email в форму и нажимает «Продолжить».
3. Встроена защита от повторной отправки формы при ошибках.
4. Изменить сохраненный адрес можно в любой момент через меню расширения Tampermonkey.

## Установка

1. Установите расширение Tampermonkey в браузер.
2. Установите файл `ejudge-autologin.user.js`.
